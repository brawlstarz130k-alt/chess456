Grandmaster Studio — مشروع أندرويد جاهز لبناء ملف APK
=====================================================

لديك طريقتان سهلتان لتحويل هذا المشروع إلى ملف APK جاهز للتثبيت على هاتفك:

الطريقة 1 (الأسرع والأسهل — بدون تثبيت أي برامج على جهازك، خلال دقيقتين):
1. أنشئ مستودعاً جديداً مجانياً على GitHub (github.com).
2. ارفع جميع ملفات هذا المجلد (بما فيها مجلد .github).
3. ادخل إلى تبويب Actions في المستودع، سيبدأ بناء ملف APK تلقائياً.
4. بعد دقيقتين، اضغط على Grandmaster-Studio-APK لتحميل ملف app-debug.apk وتثبيته مباشرة على هاتفك!

الطريقة 2 (على كمبيوترك عبر Android Studio):
1. افتح هذا المجلد في Android Studio.
2. انتظر اكتمال مزامنة Gradle.
3. من القائمة العلوية اختر: Build > Build Bundle(s) / APK(s) > Build APK(s).
4. ستجد الملف الجاهز في: app/build/outputs/apk/debug/app-debug.apk

ملاحظة: التطبيق يعمل 100% بدون إنترنت بعد التثبيت مع محرك الشطرنج المدمج والمساعد الشخصي للفوز.
